# Tower Defense Refactor
Voor mijn refactor heb ik gekozen voor mijn oude tower defense project. Hierin wil ik mijn Enemy systeem verbeteren zodat ze beter pathfinden en andere soorten snelheden en damage hebben. De huidige staat van de refactor gaat alleen nog meer over andere fundamentele systemen in het project waaronder een nieuw health system en nieuw construction system voor alle structuren, maar ook een upgrade van Unity 2022 naar Unity 6.3. Ik heb gekozen voor het refactoren van deze systemen en de Unity upgrade omdat de codebase van de systemen nogal moeilijk te begrijpen waren en er veel expensive calls werden aangeroepen. 

## Belangrijk
De build slaat save data op in een json bestand op in:
C:\Users\user\AppData\LocalLow\DaanBanaan\Apocalypse TD
Deze folder kan je na het spelen verwijderen.
